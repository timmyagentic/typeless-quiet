# Typeless++ v0.0.1 Beta 1

首个以 **Typeless++** 品牌发布的 macOS Beta。

## 主要能力

- 自动关闭已知的 Typeless 瞬时升级提示，保留唯一目标、唯一按钮和动作前复验。
- 本地管理已有账号，只读显示当前账号与额度；秘密按账号 UUID 保存在 macOS Keychain。
- 通过 Typeless 官方登录页发起安全切换，仅在目标邮箱和本次操作后的新鲜额度都可读时成功。
- 可选低额度守护：阈值、有序账号池、冷却和失败退避；录音/处理、陈旧或歧义状态 fail closed。
- schema v1 无秘密备份与保守迁移；不复制 Keychain、额度 runtime/audit 或 Typeless 设备身份。

## 下载

- 推荐：`TypelessPlusPlus-0.0.1-beta.1-macos-arm64.dmg`
- 备用：`TypelessPlusPlus-0.0.1-beta.1-macos-arm64.zip`
- 两种资产均附带 `.sha256` 校验文件。

App 版本为 `0.0.1 (7)`，支持 macOS 13+ Apple Silicon。保留旧 Bundle ID
`io.github.timmyagentic.TypelessQuiet`，用于兼容已有辅助功能授权、偏好和登录项。

## 安装

打开 DMG，将 `Typeless++.app` 拖入 Applications，然后从 Applications 启动并按系统要求授予
“设备控制和数据访问”（部分 macOS 显示为“辅助功能”）权限。

## Beta 边界

- Typeless 是非官方集成；Typeless++ 与 Typeless 或 Simply LLC 无隶属、授权或合作关系。
- 服务器下发的真实瞬时升级弹窗尚未完成当前版本现场自动关闭 E2E。
- 真实账号切换/恢复没有使用用户目标账号执行端到端验证；操作始终依赖 Typeless 官方登录。
- 低额度守护默认关闭，数据陈旧、录音/处理、目标歧义或冷却中都不会切换。
- 备份包含邮箱和用户备注，但不含应用管理的秘密或设备身份；仍应按个人资料妥善保管。
